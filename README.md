# Midamos el Pulso de tu Negocio

Diagnóstico gratuito de **Kleyi Elimar | Consultoría de Negocios**. Página web
independiente (un solo archivo, `index.html`) que la persona responde en ~4 minutos
y descarga su plan de acción en PDF.

## Qué hay aquí

- **`index.html`** — el diagnóstico completo. Autónomo: tipografía, estilos y lógica
  van dentro del archivo. No depende de ningún servicio externo (solo carga la fuente
  Montserrat desde Google Fonts).

## Enlace público

Servido con GitHub Pages en:

```
https://kleyielimar.github.io/organizar-tu-empresa/
```

Para saludar por su nombre (opcional): añade `?nombre=Maria` al final del enlace.

## Cómo publicarlo o actualizarlo

1. Sube o reemplaza `index.html` en la rama `main`.
2. Actívalo una sola vez en **Settings → Pages** → Source: `main` / `/(root)`.
3. En ~1 minuto el enlace de arriba muestra la última versión.

## Importante

Esta página **no captura correos**. La captura de nombre, apellido y correo se hace
en el formulario de **Systeme.io**, que luego redirige a este enlace y lo envía por
email. Aquí solo vive la experiencia del diagnóstico.
